# Biblia — citește, ascultă și studiază — APK

Generat cu Zamolxis AI. Deschide https://biblia.zamolxis.app/ într-o aplicație Android (browser simplu).

## Cum obții APK-ul (fără programare)
1. Creează un cont gratuit pe github.com și apasă **New repository**.
2. Apasă **uploading an existing file** și trage aici TOT conținutul acestui folder (inclusiv folderul .github).
3. Mergi la tab-ul **Actions** — construirea pornește singură (~5 minute).
4. Deschide rularea terminată și descarcă **app-apk** de la secțiunea Artifacts.
5. Copiază fișierul .apk pe telefon și instalează-l (permite „surse necunoscute”).

Pentru Google Play ai nevoie de o versiune semnată (AAB) — vezi documentația Capacitor.
